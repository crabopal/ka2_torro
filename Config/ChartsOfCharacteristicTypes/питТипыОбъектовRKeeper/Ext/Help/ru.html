План видов характеристик «Типы объектов R-Keeper»

Назначение

 

Предназначен для хранения и создания типов объектов R-Keeper.

 

Реквизиты

 

  • Наименование. Тип объекта R-Keeper.
  • Тип значения. Тип данных 1С.
  • Служебный каталог. Служит для выбора группы справочника, в которую будут переносится созданные/обновленные объекты 1С. Если значение не выбрано, то объекты будут переносится в корневой уровень справочника.
  • При ошибках загрузки. Выбор поведения программы при возникновении ошибок загрузки:
    • Продолжать загрузку – загрузка продолжается при возникновении ошибок
    • Не загружать данный чек – при возникновении ошибки не будет загружен чек, в котором она произошла
    • Прервать загрузку чеков – при возникновении первой ошибки загрузка будет прекращена
  • Создавать новые элементы данного типа при загрузке. Указывает на необходимость создавать объекты 1С при ненахождении соответствий с объектами R-Keeper.
  • Обновлять существующие элементы данного типа при загрузке. Указывает на необходимость синхронизации имеющихся объектов 1С с объектами R-Keeper. 

 

Формы

 

  • Форма списка. Основная форма списка. Используется для отображения списка элементов.
  • Форма элемента. Основная форма объекта. Используется для заполнения обязательных реквизитов.
