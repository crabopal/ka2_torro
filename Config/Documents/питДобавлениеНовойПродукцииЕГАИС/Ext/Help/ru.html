Документ «Добавление новой продукции в ЕГАИС»

Для того чтобы внести данные о производимой продукции в ЕГАИС, используется документ Добавление новой продукции в ЕГАИС.На форме документа заполняется информация о новой продукции, и затем эти сведения отправляются в ЕГАИС по кнопке Отправить в ЕГАИС. Данные из ЕГАИС затем загружаются в Классификатор алкогольной продукции ЕГАИС.
