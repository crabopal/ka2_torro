Назначение

 

Документ предназначен для хранения первичных данных о продажах из фронт-офиса. Каждый документ соответствует чеку на стороне фронт-офиса. Документ может быть создан вручную или загружен при обмене с фронт-офисом.

Вид документа зависит от операции, которая может принимать следующие значения:

  • Продажа. Используется для регистрации факта продажи блюд и услуг.
  • Возврат. Используется для регистрации факта возврата блюд и услуг.
  • Отмена. Используется для регистрации факта отмены реализации блюд и услуг (чек с отмененными позициями).
  • Предоплата. Используется для регистрации факта внесения предоплаты.
  • Возврат предоплаты. Используется для регистрации факта возврата предоплаты.
  • Учет алкоголя. Используется для регистрации факта учета алкогольной продукции.
  • Неподдерживаемая операция. Используется для регистрации чека с неподдерживаемой системой операцией.

      На основании данного документа далее с помощью обработки Загрузка из чеков общепита формируются целевые документы:

      • Выпуск с розничной реализацией
      • Выпуск блюд со списанием
      • Выпуск блюд с перемещением
      • Отчет о розничных продажах 
       

      При загрузке чеков общепита ранее созданный документ обновляется, при этом в регистре сведений Чеки общепита фиксируется необходимость последующего обновления учетных документов.

       

      Закладка «Основное»

      • Вид операции. Определяет вид документа, который может принимать следующие значения: Продажа, Возврат, Отмена, Предоплата, Возврат предоплаты, Учет алкоголя и Неподдерживаемая операция.
      • Организация. Идентификатор юридического лица, от которого выписан документ. Ссылается на справочник Организации.
      • Подразделение. Производственное подразделение организации, в котором были оказаны внутренние услуги. Реквизит является обязательным для заполнения. Значение реквизита выбирается из справочника Структура предприятия.
      • Зал. Место обслуживания гостя. Ссылается на справочник Залы. 
      • Касса ККМ. Касса ККМ, на которой оформлен документ, то есть, пробит чек. Ссылается на справочник Кассы ККМ.
      • Номер смены. Номер смены фискального регистратора, на котором пробит чек.
      • Номер чека. Номер чека фискального регистра, на котором пробит чек.
      • Гость. Конечный потребитель, идентифицируемый с помощью своей карточки при продаже во фронте. Является дополнительной аналитикой чеков общепита. Ссылается на справочник Гости. 
      • Дисконтная карта. Определяет карточку, предоставляющую право на получение скидки. Ссылается на справочник Карточки.
      • Документ продажи. Документ, по которому произведен возврат всех или части позиций текущего документа. Доступен только для операции Возврат. Ссылается на документ Чеки общепита.
      • Ответственный. Автор документа - пользователь, создавший документ. Ссылается на справочник Пользователи.
      • Чек возврата. Документ, по которому произведен возврат всех или части позиций текущего документа. Ссылается на документ Чеки общепита.
      • Комментарий. Произвольный комментарий к документу.

       

      Закладка «Товары»

       
      • Номенклатура. Реализованная во фронт-офисе позиция или номенклатура модификатора. Реквизит является уникальным и обязательным для заполнения. Ссылается на справочник Номенклатура.
      • Количество. Количество единиц измерения номенклатуры. Если задан модификатор, равно количество модификатора*количество номенклатуры модификатора. Реквизит является обязательным для заполнения.
      • Ед. изм. Единица измерения номенклатурной позиции. Реквизит является уникальным и обязательным для заполнения. Ссылается на справочник Упаковки и единицы измерения. 
      • Цена. Розничная цена позиции.
      • Сумма. Сумма реализации.
      • Ставка НДС. Ссылается на перечисление «Ставки НДС»
      • Сумма НДС. Сумма НДС. Обычно входит в состав суммы реализации
      • Всего. Итоговая сумма по строке с учетом скидок и НДС.
      • Место печати. Место печати позиции (расположение принтера для печати заказов). Ссылается на справочник Места печати.
      • Дата отмены. Дата и время отмены позиции. Доступно только для операции Отмена.
      • Со списанием. Признак необходимости списания позиции, так как позиция была уже приготовлена к моменту отмены. Доступно только для операции Отмена.
      • Причина отмены. Причина отмены позиции. Доступно только для операции Отмена. Ссылается на справочник Причины отмен и списаний.

       

      Закладка «Модификаторы»

       
      • Номенклатура основной позиции. Номенклатура, с которой используется данный модификатор. Ссылается на справочник Номенклатура.
      • Модификатор. Модификатор, реализованный во фронт-офисе. Всегда связан с номенклатурой основных позиций. Ссылается на справочник Модификаторы. 
      • Количество. Количество единиц модификатора. Имеет смысл только при заполненном модификаторе. Если модификатор не указан, равно 0.
      • Номенклатура. Номенклатура, из которой готовится модификатор. Ссылается на справочник Номенклатура.  
      • Цена. Цена модификатора.
      • Сумма. Сумма реализации модификатора.
      • Количество номенклатуры. Количество требуемой номенклатуры для модификатора.
      • Единица. Единица измерения номенклатуры требуемой для модификатора.

       

      Закладка «Оплаты»

      • Вид оплаты. Определяет способ оплаты заказа во фронт-офисе. Реквизит является уникальным и обязательным для заполнения. Ссылается на справочник Виды оплат.
      • Фискальный. Определяет фискальность вида оплаты. Необходим для хранения информации о фискальности для возможных обновлений документа.
      • Карточка. Талон или карта питания сотрудника, являющиеся средством оплаты. Ссылается на справочник Карточки.
      • Сумма оплаты. Сумма внесенной оплаты. При оплате талоном может быть не равна сумме реализации, а быть равной (Количество талонов * Номинал талона).
      • Сдача. Сумма сдачи в случае вида оплаты с типом «Наличные» или неиспользованный остаток талона в случае вида оплаты с типом «Талоны и купоны».
