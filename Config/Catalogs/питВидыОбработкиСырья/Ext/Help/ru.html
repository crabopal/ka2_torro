Справочник "Виды обработки сырья"

Назначение

Хранит список возможных видов обработки сырья при приготовлении блюд. Используются для задания процентов потерь сырья в процессе приготовления.

Относится к подсистеме: «Производство».

Параметры

Длина кода: 8, тип кода: Число.

Длина наименования: 25.

Не иерархический.

Реквизиты

  • Тип обработки сырья. Указывает, к холодному или горячему типу обработки относится данный вид обработки сырья.

Способ вызова

Вызывается из меню "Справочники --> Производство--> Механизм видов обработки --> Виды обработки сырья".
