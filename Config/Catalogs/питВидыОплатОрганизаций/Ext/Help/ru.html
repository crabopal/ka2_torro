Справочник «Виды оплат»

Назначение

Справочник предназначен для хранения информации о различных видах оплаты товаров и услуг розничным покупателем. 

Вид оплаты указывается в документе Отчет о розничных продажах и Выпуск блюд с хоз. операцией «Выпуск с розничной реализацией».

Каждый вид оплаты характеризуется Способом оплаты. Возможны следующие способы оплаты:

  • Наличные

  • Платежная карта
  • Банковский кредит
  • Талоны и купоны
  • Питание сотрудников
  • За счет заведения
  • Клубная карта
  • Подарочный сертификат собственный
  • Подарочный сертификат сторонний

При вводе вида оплаты также необходимо указать контрагента, договор контрагента, счет учета расчетов. При необходимости можно указать процент банковской комиссии.

Реквизиты

  • Способ оплаты. Предопределенный способ оплат.
  • Наименование. Наименование Вида оплат.

Закладка «Общие настройки»

  • Фискальный (требуется наличие в видах оплат фискального регистратора).  Признак фискального типа оплат.
  • Ведущий (является основным типом оплаты). В документе продажи может присутствовать только одна оплата с признаком Ведущий.
  • Разрешаются нулевые суммы. Разрешает указать нулевую сумму платежа по данному типу оплату для оформления факта продажи на нулевую сумму.
  • Персонификация платежа (необходимость детализации с помощью карточки). Определяет необходимость при вводе платежа по данному типу оплаты дополнительно указывать идентификационную карту.
  • Организация. Организация, к которой относится данный вид оплат. Ссылается на справочник Организации.  
  • Контрагент. Контрагент, по договору с которым будет производится безналичная оплата. Ссылается на справочник Контрагенты.  
  • Договор. Договор с банком-эквайрером на прием оплаты с помощью платежных карт в случае, если он заключен для отдельного типа безналичной оплаты. Для оплаты картой сотрудника или талоном будет использоваться индивидуальный договор, указанный для каждой отдельной карточки сотрудника (талона). Ссылается на справочник Договоры контрагентов.
  • Терминал. Эквайринговый терминал. Ссылается на справочник Подключаемое оборудование.
  • Банковская комиссия. Процент банковской комиссии, взымаемой банком при безналичной оплате.
  • Вид операции. Обязательный реквизит для заполнения. Вид операции, используемый в обработке Загрузка из чеков общепита для определения  целевых документов. Могут быть: Списание, Реализация, Не загружать. При первом заполнении рабочей базы автоматически устанавливаются как Реализация. 
  • Статья доходов и расходов. Ссылается на справочник Статьи расходов.

Закладка «Фронт-офис»

  • Имя группы. Имя группы используется во фронт-офисном ПО для группировки типов оплат (типы оплат с одинаковым значением данного реквизита будут группироваться вместе).
  • Порядковый номер кнопки. Порядковый номер кнопки типа оплаты во фронт-офисе.
  • Цвет фона кнопки. Цвет фона кнопки типа оплаты во фронт-офисе.
  • Цвет основной надписи. Цвет шрифта надписи 1 (верхней) кнопки типа оплаты во фронт-офисе.
  • Цвет надписи в нижнем правом углу. Цвет шрифта надписи 2 (нижней правой) кнопки типа оплаты во фронт-офисе.
  • Цвет надписи в нижнем левом углу. Цвет шрифта надписи 2 (нижней левой) кнопки типа оплаты во фронт-офисе.
