Справочник «Наборы модификаторов»

Назначение

 

Предназначен для задания различных наборов из элементов справочника Модификаторы. Каждый модификатор может быть помещен в любое количество наборов. Наборы применяются для «группового» назначения применимости модификаторов к номенклатуре.

 

Реквизиты

 

  • Наименование. Наименование набора модификаторов.

 

Закладка «Модификаторы»

 

  • Модификатор. Модификатор номенклатуры. Реквизит является уникальным и обязательным для заполнения. Ссылается на справочник Модификаторы.

 

Закладка «Параметры»

 

  • Цвет фона кнопок. Задает цвет фона у кнопок с модификаторами при подборе из данного набора во фронт-офисе.
  • Контролировать количество при выборе из данного набора. Флаг,  указывающий выполнять или нет контроль количества выбранных модификаторов при подборе во фронте.
  • Минимальное количество модификаторов. Минимальное количество модификаторов, которое необходимо указать к основному блюду при подборе во фронте. При нулевом значении подбор модификаторов из данного набора не является обязательным (ограничения «снизу» нет).
  • Максимальное количество модификаторов. Максимальное количество модификаторов, которое допустимо указать к основному блюду при подборе во фронте. При нулевом значении количество подбираемых модификаторов из данного набора не ограничивается (ограничения «сверху» нет)
