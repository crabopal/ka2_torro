Справочник «Гости»

Назначение

Используется для идентификации конечных потребителей услуг. Гость является клиентом, которого можно однозначно идентифицировать по данным его карточки в случае ее считывания с помощью оборудования или ввода кода вручную. Таким образом, появляется возможность определения гостя при его последующем обслуживании.

 

Реквизиты

  • Наименование. Реквизит является обязательным для заполнения. Наименование элемента или группы справочника.
  • Фамилия. Реквизит является обязательным для заполнения. Фамилия гостя.
  • Имя. Реквизит является обязательным для заполнения. Имя гостя.
  • Отчество. Отчество гостя.
  • Дата рождения. Дата рождения гостя.
  • День рождения. День рождения гостя в формате День - Месяц.
  • Контактный телефон. Основной контактный телефон.
  • Дополнительный телефон. Дополнительный контактный телефон.
  • Почтовый адрес. Почтовый адрес гостя.
  • Адрес доставки. Почтовый адрес для доставки.
  • Адрес e-mail. Адрес электронной почты.
  • Логин. Для задания имени пользователя в личном кабинете гостя.
  • Пароль. Служит для доступа в личный кабинет или для идентификации гостя по телефону.
  • Комментарий. Произвольный текст.
