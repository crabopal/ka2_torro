Справочник «Группы ХЭХ»

Назначение

Справочник содержит перечень групп химико-энергетических характеристик (ХЭХ).

В состав группы ХЭХ может входить неограниченное количество химико-энергетических характеристик, но один элемент химико-энергетических характеристик может входить только в одну группу ХЭХ.

Справочник содержит несколько предопределенных элементов: «Витаминная», «Витамины группы B», «Микроэлементы», «Основная».

 

Реквизиты

  • Наименование. Наименование группы ХЭХ.

Закладка «Состав группы»

Содержит перечень химико-энергетических характеристик входящих в группу.
