Справочник «Учетная запись StoreHouse HeadOffice»

Назначение

Справочник содержит перечень учетных записей для подключения к разным информационным базам StoreHouse HeadOffice.

 

Реквизиты

  • Наименование. Наименование учетной записи.
  • Сервер. Имя сервера MS SQL Server, на котором установлен и функционирует StoreHouse HeadOffice.
  • БД. База данных StoreHouse HeadOffice на сервере MS SQL Server, с которой осуществляется обмен.
  • Логин и пароль. Логин и пароль администратора базы StoreHouse HeadOffice. При незаполненных значениях аутентификация будет происходить по текущему пользователю Windows.
  • Начинается с. Указывается дата, начиная с которой будут загружены данные из базы StoreHouse HeadOffice при первом фоновом обмене.  

По кнопке Проверить подключение можно проверить как пройдет подключение по указанным параметрам. 

 

Способ вызова

 

Непосредственно из обработки Загрузка из StoreHouse HeadOffice.
