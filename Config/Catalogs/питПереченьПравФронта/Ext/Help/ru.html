Справочник «Перечень прав фронта»

Назначение

Предназначен для хранения перечня прав пользователей фронт-офиса. Справочник доступен только для просмотра, редактирование и актуализация прав производится на стороне фронт-офиса.

Реквизиты

  • Наименование. Наименование права.
  • Комментарий. Содержит описание данного права.

Способ вызова

Общепит - Обмены с фронт-офисом - Перечень прав фронта
