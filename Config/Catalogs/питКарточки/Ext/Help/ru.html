Справочник «Карточки»

Назначение

Справочник предназначен для хранения карточек, которые идентифицируют другие объекты системы при помощи оборудования (считыватель карт), а также в целях персонификации платежа. Карточка может быть использована несколькими способами: платежная, дисконтная, авторизации, служебная. При этом допускается задание сразу нескольких способов использования.

 

Реквизиты

  • Наименование. Наименование карты.
  • Данные карты. Содержит данные карты для идентификации оборудованием (например, штрих-код).
  • Платежная (используется для детализации платежей). Предоставляет возможность использования карточки для детализации платежа.
  • Дисконтная (является условием для предоставления скидки). Предоставляет возможность использования карточки в качестве условия скидки при продаже.
  • Авторизация (идентификация пользователей системы). Предоставляет возможность использования карточки для авторизации пользователей системы.
  • Служебная (выполнение служебных операций). Предоставляет возможность использования карточки для выполнения служебных операций, например, для завершения работы системы.
  • Заблокирована (временно не используется). Устанавливает временную недоступность карточки для использования.
  • Дата активации. Дата и время создания/активации карточки.
  • Дата прекращения действия. Дата и время окончания действия (закрытия) карточки.
  • Комментарий. Произвольный комментарий к карточке.

 

Закладка «Платежная»

  • Вид оплаты. Является обязательным для заполнения для платежных карт. Идентифицирует связанный с платежной карточкой тип оплаты. Ссылается на справочник Виды оплат.
  • Контрагент. Является обязательным для заполнения для платежных карт. Контрагент, с которым ведутся взаиморасчеты при операциях с помощью карточки. Ссылается на справочник Контрагенты.
  • Договор. Является обязательным для заполнения для платежных карт. Договор контрагента, по которому ведутся взаиморасчеты при операциях с помощью карточки. Ссылается на справочник Договоры с контрагентами.
  • Гость. Идентифицирует гостя (конечного потребителя) при использовании карточки. Ссылается на справочник Гости.
  • Сотрудник. Определяет сотрудника организации при использовании карточки для оплаты питания сотрудников. Ссылается на справочник Сотрудники.
  • Статья списания. Статья списания при регистрации продажи с участием карточки как списания. Ссылается на справочник Причины отмен и списаний.
  • Кратность платежа. Определяет номинал талона.
  • Мастер-карта. Определяет карточку, с которой будут списываться средства при оплате данной карточкой. Ссылается на справочник Карточки.

 

Закладка «Дисконтная»

  • Сумма накопленная. Сумма операций, произведенных с помощью карточки.
  • Гость. Идентифицирует гостя (конечного потребителя) при использовании карточки. Ссылается на справочник Гости.

 

Закладка «Авторизация»

  • Пользователь. Является обязательным для заполнения для карт авторизации. Пользователь системы, определяемый карточкой. Ссылается на справочник Пользователи.

 

Закладка «Служебная»

  • Код служебной операции. Является обязательным для заполнения для служебных карт. Код определенной служебной операции.
