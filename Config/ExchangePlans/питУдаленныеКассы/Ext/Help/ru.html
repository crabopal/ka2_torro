Назначение

Предназначен для обмена данными между территориально удаленными кассами компании и центральной информационной базой. Каждая отдельная касса компании может обмениваться данными только с одним узлом информационной системы - центральной базой. Центральная информационная база, в свою очередь, может иметь неограниченное количество подчиненных касс, с которыми возможен обмен данными.

План обмена содержит информацию об узлах, которые могут участвовать в обмене данными, определяет способ доставки и приема сообщений обмена. Для каждого узла можно задать код, наименование и необходимый перечень реквизитов, описывающих узел.

Данный план обмена предназначен для обмена данными между разнородными конфигурациями «1С:Общепит. Модуль для 1С:ERP» в качестве бэк-офиса и «1С:Предприятие 8. Ресторан»,  «РестАрт» в качестве фронт-офиса.

 

Реквизиты

  • Наименование. Наименование кассового узла.
  • Префикс. Реквизит является уникальным и обязательным для заполнения. Префикс автонумерации для документов (до 20 символов).  

Закладка «Основные настройки»

  • Организация. Устанавливает основную организацию кассового узла. Ссылается на справочник Организации.
  • Подразделение. Подразделение, которому принадлежит данный узел. Ссылается на справочник Структура предприятия.
  • Склад приготовления. Склад приготовления по умолчанию, который используется при загрузке чеков общепита. Ссылается на справочник Склады и магазины.
  • Склад реализации. Склад реализации по умолчанию, который используется при загрузке чеков общепита. Ссылается на справочник Склады и магазины.
  • Комментарий. Произвольный комментарий к кассовому узлу.

Закладка «Данные обменов»

  • Версия фронт-офиса. Номер релиза фронт-офиса. Не редактируется. Данные заполняются на основании сообщений обмена. 
  • Настройка доставки по умолчанию. Настройка доставки сообщения обмена для данного узла. Ссылается на справочник Настройки доставки сообщений.

Закладка «Загрузка документов»
  • Загружать отмены без списания. Определяет необходимость загрузки строк чеков общепита, отмененных без списания.
  • Выполнять загрузку из чеков общепита. Задает необходимость создания целевых документов на основании чеков общепита после загрузки. 
  • Запретить повторную загрузку чеков общепита. Документы будут формироваться только из новых продаж фронта. Существующие обновленные данные в документах будут игнорироваться.
  • Проводить загружаемые документы. Признак проведения документов, загружаемых из чеков общепита.
  • Загрузка чеков общепита в производственные документы. Будет производиться загрузка в документы Выпуск блюд.  
  • Статья калькуляции. Статья калькуляции, которая будет указана при формировании документов по данным продаж.
  • Разрешить недовложения. В документе Выпуск блюд устанавливается соответствующий флаг.
  • Учитывать остатки блюд на складе. В документе Выпуск блюд устанавливается соответствующий флаг.
  • Загружать товары в выпуск с перемещением. При установленном флаге в документ Выпуск блюд с хоз. операцией «Выпуск блюд с перемещением», будет попадать номенклатура с типом «Товар» и так же будет реализовываться документом Отчет о розничных продажах. Если флаг не установлен, то товары будут только в документе Отчет о розничных продажах, а в «Выпуск блюд с перемещением» не попадут.    
  • Эквайринговый терминал. Эквайринговый терминал, который будет указан при формирований документов розничных продаж при оплате картой.
  • Счет учета оплаты.  Счет, который будет использоваться в виде подарочных сертификатов, при условии, что на стороне фронт-офиса была произведена оплата талоном. Ссылается на План счетов бухгалтерского учета.

Закладка «Кассы ККМ» 

  • Касса ККМ. Отображает кассы ККМ, выгружаемые в кассовый узел. Соответствие кассового узла и кассы ККМ производится с помощью справочника Кассы ККМ. 

 Закладка «Виды меню»

  • Вид меню. Реквизит является уникальным и обязательным для заполнения. Вид меню, выгружаемый во фронт-офис. Ссылается на справочник Виды меню. 
  • Вид цены. Задает вид цены, соответствующей виду меню номенклатуры. Ссылается на справочник Виды цен. 

Закладка «Доп. организации»

  • Организация. Реквизит является уникальным и обязательным для заполнения. Организация, дополнительно выгружаемая во фронт-офис. Ссылается на справочник Организации.
  • Подразделение. Подразделение, в разрезе которого определяется цена номенклатуры дополнительной организации при выгрузке во фронт-офис. Ссылается на справочник Структура предприятия.

Закладка «Залы»

  • Зал. Реквизит является уникальным и обязательным для заполнения. Зал, выгружаемый во фронт-офис. Ссылается на справочник Залы.

Закладка «Места печати»

  • Место печати. Реквизит является уникальным и обязательным для заполнения. Место печати, выгружаемые во фронт-офис. Ссылается на справочник Места печати.

Маршрутизация печати:

  • Правила маршрутизации печати задаются только на стороне кассового узла (по обменам не передаются). Обмен данными о маршрутизации между узлами плана обмена не производится. 
  • Общие настройки маршрутизации для всех кассовых узлов. Устанавливает использование настроек маршрутизации печати, общих для всех кассовых узлов.
  • Настройки печати для данного кассового узла. Устанавливает использование настроек маршрутизации печати, заданных для данного кассового узла.

Кнопка Настроить правила... позволяет настроить правила маршрутизации.
