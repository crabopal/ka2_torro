Форма «Структура учетных документов»

Назначение

Предназначен для вывода родительских и подчиненных документов.

Форма предоставляет оперативный и наглядный доступ ко всей цепочке взаимосвязанных с точки зрения бизнес-логики документов. Документы считаются взаимосвязанными, если один документ ссылается на другой. В программе взаимосвязь документов выглядит так: в одном документе (назовем его дочерним) в качестве какого-либо реквизита указан другой документ (назовем его родительским). Отчет позволяет из какого-либо одного документа увидеть всю цепочку взаимосвязанных с ним документов.

В отчет попадают все дочерние и все родительские документы текущего документа. В наглядной форме представлена взаимосвязь этих документов.

Документ, для которого сформирован отчет, отображается жирным шрифтом. Дерево родительских документов строится вверх-вправо от документа, для которого формируется отчет. Дерево дочерних документов строится вниз-вправо от документа, для которого формируется отчет.

 

Доступные действия:

  • С помощью двойного щелчка мышью на любом выведенном в отчет документе можно открыть данный документ для просмотра.
  • С помощью кнопки Обновить можно переформировать отчет.

 

Способ вызова

Формируется командой Структура учетных документов на панели навигации документа.
