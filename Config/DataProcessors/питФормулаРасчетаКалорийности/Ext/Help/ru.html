Обработка «Формула расчета калорийности»

Назначение

Обработка Формула расчета калорийности служит для ввода и редактирования формулы расчета калорийности, исходя из количества других химико-энергетических характеристик.  При вводе контролируется синтаксическая структура формулы, поэтому пользователь не сможет в результате использовать некорректную формулу. Редактирование производится с использованием цифровой панели и панели ХЭХ. Первая панель доступна и с цифровой части клавиатуры. В формулу можно вводить только предопределенные ХЭХ, причем они представлены своими именами, а не наименованиями, во избежание проблем с вычислением формулы при смене наименований ХЭХ.

 

По умолчанию в настройках параметров учета определена формула:

4 * [Белки] + 9 * [Жиры] + 4 * [Углеводы] + 7 * [Алкоголь]

Способ вызова

 

Вызывается для реквизита с формулой расчета калорийности из справочника Номенклатура, закладка ХЭХ.

 

Из документа Рецептуры (закладка Химико-энергетические характеристики).

 

Из формы Настроек (Общепит – Настройки - ХЭХ).
