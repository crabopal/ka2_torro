Назначение

Обработка предназначена для формирования типовых документов «1C:ERP» по имеющимся в системе документам подсистемы «Общепит». 

Алгоритм формирования типовых документов необходим для обеспечения связи модуля «Общепит» и бизнес-процессов, протекающих в нем с системой «1C:ERP» в целом. По данным документов «Общепит» по установленным правилам происходит формирование документов «1C:ERP», а также их синхронизация и обновление. Формирование типовых документов может происходить в синхронном и асинхронном режимах. 

В синхронном режиме связанные типовые документы создаются/обновляются непосредственно в момент записи документа «Общепит».

В асинхронном режиме создание/обновление связанных документов происходит вручную по имеющимся в системе документам «Общепит» при помощи данной обработки по нажатию на кнопку Выполнить.

Сформированные документы связаны с отраслевыми посредством специального регистра сведений Типовые документы. Установленная связь между документом модуля «Общепит» и типовым документом означает невозможность самостоятельного изменения типового документа. Следовательно, форма такого документа будет доступна исключительно в режиме просмотра, а любая попытка записать/провести/пометить на удаление документ приведет к отказу. Изменение такого документа возможно только путем изменения родительского документа «Общепит» и дальнейшей синхронизации связанных с ним документов. Таким образом обеспечивается целостность и адекватность введенных данных.

Документы «Общепит», по которым создаются типовые документы «1C:ERP»: Выпуск блюд, Разделка, План-меню, Рецептура.

Правила создания типовых документов

Типовые документы по документу «Выпуск блюд». Документ Выпуск блюд является центральным документом модуля «Общепит» и является основой для создания целого ряда типовых документов «1С:ERP». В частности по одному документу данного типа формируются один или несколько документов следующих типов: 

  • Передача материалов в производство. Данный типовой документ формируется по данным таблицы ингредиентов документа Выпуск блюд. Документ регистрирует факты выдачи материалов со склада в производство. Для каждого Выпуск блюд создается один документ Передача материалов в производство.
  • Выпуск продукции. Типовой документ Выпуск продукции формируется на основании табличной части «Блюда». Особенностью данного типового документа является наличие направления выпуска. Это может быть выпуск «На склад» либо выпуск «В подразделение». Таким образом, для каждого документа общепит Выпуск блюд создается два документа Выпуск продукции с разными направлениями выпуска. В документ с направлением «На склад» попадет та номенклатура из табличной части «Блюда», у которой НЕ установлен флаг «Автопередел». Остальные позиции номенклатуры попадают в документ с направлением выпуска «В подразделение».
  • Списание затрат на выпуск. Типовой документ Списание затрат на выпуск формируется на основании данных табличных частей «Блюда» и «Ингредиенты» документа Выпуск блюд. В шапке документа и в табличной части «Выходные изделия» содержится номенклатура, соответствующая табличной части «Блюда». При этом табличная часть всегда содержит только одну строку. Таким образом, создается такое количество документов Списание затрат на выпуск, которое соответствует количеству строк в табличной части «Блюда» документа Выпуск блюд. Табличная часть «Материалы и работы» заполняется на основе данных из табличной части «Ингредиенты» документа Выпуск блюд, отобранных исходя из текущей номенклатуры, для которой оформляется документ Списание затрат на выпуск.
  • Отчет о розничных продажах. Документ Отчет о розничных продажах будет сформирован только при условии, что у документа Выпуск блюд реквизит операция определен как «Выпуск с розничной реализацией». Отображает факт розничной реализации продукции, выпускаемой документом Выпуск блюд. Создается по данным таблицы «Товары». Для каждого выпуска с розничной реализацией будет создан один документ Отчет о розничных продажах.
  • Перемещение товаров. Документ Перемещение товаров будет сформирован только при условии, что у документа Выпуск блюд реквизит операция определен как «Выпуск с перемещением». Отображает факт перемещения продукции между складами предприятия в момент ее выпуска. Создается по данным таблицы «Товары». Для каждого выпуска с перемещением будет создан один документ Перемещение товаров.

Типовые документы по документу «Разделка». Документ Разделка служит для отражения в учете фактов разделки товаров на составляющие. Существуют две схемы создания типовых документов по данному документу: через создание специальных типовых документов Сборка (Разборка) товаров и через создание документов производственной схемы (Передача материалов в производство, Выпуск продукции и Списание затрат на выпуск). Таким образом, для документа Разделка могут быть созданы типовые документы «1С:ERP» следующих типов:

  • Сборка (Разборка) товаров. Типовой документ Сборка (Разборка) товаров предназначен для отражения в системе операций по сборке (разборке) комплектов. Будет создан в том случае, когда в документе Разделка в табличной части «Товары» колонка «Процент себестоимости» будет заполнена для всех позиций. Вид операции для создаваемого документа - Разборка на комплектующие. Для одного документа «Разделка» создается один документ Сборка (Разборка) товаров. Данные по комплектующим берутся из табличной части «Товары» документа Разделка.
  • Передача материалов в производство. Типовой документ Передача материалов в производство будет создан в том случае, когда в документе Разделка в табличной части «Товары» колонка «Процент себестоимости» будет заполнена НЕ для всех позиций. Данный типовой документ формируется по данным шапки документа Разделка. Документ регистрирует факты выдачи материалов (в нашем случае разделываемой продукции) со склада в производство. Для каждой Разделки создается один документ Передача материалов в производство.
  • Выпуск продукции. Типовой документ Выпуск продукции будет создан в том случае, когда в документе Разделка в табличной части «Товары» колонка «Процент себестоимости» будет заполнена НЕ для всех позиций. Данный типовой документ формируется на основании табличной части «Товары» документа Разделка. Направление выпуска – «На склад». Таким образом, для одного документа общепит Разделка может быть создан один документ Выпуск продукции, где в качестве выпускаемой продукции будут использоваться товары, полученные в результате разделки.
  • Списание затрат на выпуск. Типовой документ Списание затрат на выпуск будет создан в том случае, когда в документе Разделка в табличной части «Товары» колонка «Процент себестоимости» будет заполнена НЕ для всех позиций. Данный типовой документ формируется на основании данных табличной части «Товары» и шапки документа Разделка. В шапке документа и в табличной части «Выходные изделия» содержится номенклатура, соответствующая табличной части «Товары». При этом табличная часть всегда содержит только одну строку. Таким образом, создается такое количество документов Списание затрат на выпуск, которое соответствует количеству строк в табличной части «Товары» документа Разделка. Табличная часть «Материалы и работы» заполняется на основе данных шапки документа Разделка. В каждом из созданных выпусков в данную табличную часть будет попадать номенклатура из шапки документа Разделка, при этом количество номенклатуры будет пропорционально проценту выхода номенклатуры из табличной части «Товары», для которой создан документ Списание затрат на выпуск.  

Типовые документы по документу «План-меню». Документ План-меню предназначен для планирования выпуска продукции. По данному документу создается типовой документ Заказ материалов в производство, который отображает заказ на необходимые для планируемого производства продукции ингредиенты, указанные в документе План-меню.  

Типовые документы по документу «Рецептура». Документ Рецептура предназначен для отражения в учете калькуляций по приготовлению блюд, разделки товаров и разукомплектации. По данному документу создается типовой документ Ресурсная спецификация, который описывает процесс производства изделий.  

 

Закладка «Настройки»

  • Организация. Организация, для которой осуществляется формирование документов «1С:ERP» по существующим документам «Общепит». Если ничего не выбрано, то формирование происходит по всем организациям. Ссылается на справочник Организации.
  • Формировать по. Предельная дата документов «Общепит», по которым будет осуществляться формирование документов «1С:ERP».
  • Автоформирование типовых документов. Активизация данного переключателя включает автоматическое формирование типовых документов по документам общепит в момент их записи.
  • Формировать спецификации по рецептурам. Определяет необходимость ресурсных спецификаций по документу Рецептура. Отрабатывает, если одновременно установлен флаг Автоформирование типовых документов.

Закладка «Созданные документы»

  • Дерево документов. Дерево, которое содержит иерархию документов «Общепит» по их типам (с отбором по организации и дате, установленными на закладке «Настройки»)и связанными с ними типовыми документами ERP. Также в дереве отображается флажок синхронизации, отсутствие которого указывает на необходимость синхронизации данных типовых документов ERP по документу «Общепит». 
  • Обновить дерево документов. Кнопка обновления дерева документов.
  • Только несинхронизированные. Данный флажок устанавливает дополнительный отбор на отображаемые в дереве документы. Если флажок включен, то будут отображены только документы, для которых необходимо произвести синхронизацию.
