Настройки подсистемы «Общепит»

Общие

  • Префикс штрихкода. Префикс, который  используется при формировании штрихкодов Общепита (в справочнике Карточки при нажатии на кнопку Сформировать штрихкод).
  • Нормативная цена. Нормативный тип цен, использующийся в объектах Общепит.

Производство

  • Не изменять режим списания в производство по настройке. Признак использования настройки режима списания в производство, истина - не использовать.
  • Режим расчета списания в производство. Настройка задает режим расчета списания в производство: по норме, по факту или по норме первого проведения.
  • Статья калькуляции по умолчанию. Статья калькуляции, которая автоматически подставляется при создании документов общепит, таких как Выпуск блюд и Рецептуры.
  • Искать рецептуры по всем организациям. Признак того, что поиск рецептуры для блюд будет производиться без отбора по организации.
  • Не использовать сезонные проценты. Признак использования сезонных процентов, истина - не использовать.

ХЭХ

  • Способ расчета количества ХЭХ. Настройка определяет способ расчета химико-энергетических характеристик: по количеству Брутто, количеству Нетто либо количеству Выход.
  • Способ расчета калорийности. Настройка определяет способ расчета калорийности: суммированием либо по заданной формуле.
  • Формула расчета калорийности. Формула по которой рассчитывается калорийность при условии, что стоит режим расчета По формуле.
  • Единица измерения по классификатору для ХЭХ. Единица измерения для химико-энергетических характеристик.

Подкладные документы

  • Автоформирование типовых документов. Активизация  флага включает автоматическое формирование типовых документов по документам общепит в момент их записи.
  • Формировать спецификации по рецептурам. Определяет необходимость формирования ресурсных спецификаций по документам Рецептуры.
