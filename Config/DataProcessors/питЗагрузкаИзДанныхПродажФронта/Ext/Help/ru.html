Закладка «Настройки»

 

  • Организация. Отбор документов Чеки общепита по организации. Ссылается на справочник Организации.
  • Кассовый узел. Узел обмена. Ссылается на план обмена Кассовые узлы. 
  • Дата с /по. Дата начала и окончания отбора документов Чеки общепита.
  • Переходящая смена. Флаг, указывающий на то, что нужно учитывать смены, переходящие с одной даты на другую. Если в интервале дат начала и конца отбора имеются документы, смены которых перешли с более ранней даты (количество анализируемых дней назад определяется настройкой Дней назад для анализа), то эти документы не попадают в отбор по периоду. Если в интервале дат начала и конца отбора имеются документы, смены которых переходят на более позднюю дату (количество анализируемых дней вперед определяется настройкой Дней вперед для анализа), то будут добавлены дополнительные документы соответствующих смен.
  • Дней вперед для анализа. Число дней после даты конца отбора, которое необходимо учитывать для анализа переходящих смен.
  • Дней назад для анализа. Число дней до даты начала отбора, которое необходимо учитывать для анализа переходящих смен.
  • Дата создаваемых документов. Переключатель на три позиции, определяющий дату создаваемых целевых документов: По дате начала смены, По дате окончания смены, Фиксированная (по умолчанию устанавливается текущая дата).
  • Группировать по кассе ККМ и номеру смены. При установленном флаге загрузка и свертка данных в целевые документы происходит с учетом номеров смен.
  • Учитывать возвраты при загрузке продаж. Флаг, указывающий на то, что продажи и возвраты должны компенсировать друг друга при загрузке данных. При этом целевые документы продаж и возвратов будут созданы в любом случае, даже если они были компенсированы друг другом, но будут иметь пустую табличную часть, и не будут делать движений по регистрам учета.
  • Выводить отчет о сохраненных документах. Если флаг установлен, то после окончания всех транзакций пользователю будет выведен отчет обо всех созданных и удаленных документах.

 

Закладка «Документы для загрузки»

 

По кнопке Обновить список документов в табличную часть подтягиваются документы Чеки общепита по указанным выше отборам.  

 

Закладка «Параметры касс ККМ»

 

  • Исп. Отбор использования касс ККМ при загрузке данных.
  • Касса ККМ. Касса ККМ, на которой оформлен документ, то есть пробит чек. Реквизит является обязательным для заполнения. Ссылается на справочник Кассы ККМ.
  • Определение склада приготовления. Определяет способ определения склада приготовления блюда при загрузке документа продаж. 0 -Склад по умолчанию – склад будет установлен по реквизиту Склад приготовления по умолчанию кассового узла; 1 - По залу документа продажи - склад будет установлен по реквизиту Склад реализации зала полученного документа продажи; 2 - По месту печати документа продажи - склад будет установлен по реквизиту Склад приготовления места печати полученного документа продажи.
  • Склад приготовления. Определяет склад приготовления по умолчанию. Реквизит является обязательным для заполнения. Ссылается на справочник Склады и магазины.
  • Определение склада реализации. Определяет способ определения склада реализации блюда при загрузке документа продаж. 0 - Склад реализации по умолчанию - склад будет установлен по реквизиту Склад по умолчанию кассового узла; 1 - По залу документа продажи - склад будет установлен по реквизиту Склад реализации зала полученного документа продажи; 2 - По месту печати документа продажи - склад будет установлен по реквизиту Склад приготовления места печати полученного документа продажи.
  • Склад реализации. Определяет склад реализации по умолчанию. Реквизит является обязательным для заполнения. Ссылается на справочник Склады и магазины.
  • В документы производства. Определяет виды документов, которые будут созданы на основании чеков общепита. При установке флага будут создаваться документы Выпуск блюд с соответствующей хозяйственной операцией, иначе документы Отчет о розничных продажах. При установленном флаге появляется панель Настройки выпуска блюд: 
    • Разрешить недовложения. Устанавливает аналогичный реквизит при создании документа Выпуск блюд, который будет создан на основании чеков общепита. Если флаг установлен, то Количество ингредиента факт будет равно Количество ингредиента норма за вычетом нехватки ингредиента. Если флаг снят, то Количество ингредиента факт будет равно Количество ингредиента норма, без учета нехватки ингредиента. 
    • Учитывать остатки блюд на складе. Устанавливает реквизит «Учитывать остатки блюд на складе» документа Выпуск блюд, который будет создан на основании чеков общепита. При установленном флаге, приготовление блюд будет происходить с учетом остатков блюд на складе.
    • Загружать товары в Выпуск с перемещением. При установленном флаге в документ Выпуск блюд с хоз. операцией «Выпуск блюд с перемещением», будет попадать номенклатура с типом «Товар» и так же будет реализовываться документом Отчет о розничных продажах. Если флаг не установлен, то товары будут только в документе Отчет о розничных продажах, а в «Выпуск блюд с перемещением» не попадут.  
  • Проводить документы. Устанавливает необходимость проведения загруженных документов продаж. Если флаг не установлен, документы должны быть проведены позже вручную после создания. 
  • Запретить повторную загрузку документов. Запрещает повторное создание документов на основе чеков общепита. При установленном флаге документы продаж, созданные ранее, помечаются на удаление.

Параметры для касс ККМ могут быть загружены автоматически из соответствующих узлов обмена (меню Заполнение), а также сохранены (меню Сохранение настроек, при этом сохраняются соответствующие кассовые узлы). Сохранение и загрузка настроек может быть произведена как для текущей выделенной строки, так и для всех сразу.

 

 

Алгоритм работы обработки

 
  1. На основной форме выбираются документы для обработки с помощью снятия/установки флагов в таблице документов и задания отборов по дате, организации и кассового узла. Документы, для которых не могут быть определены типы целевых документов, не обрабатываются и помечаются в таблице красным цветом.
  2. При нажатии кнопки Выполнить загрузку происходит обработка выбранных документов и загрузка данных в целевые документы. При повторной перегрузке документов создаются не новые, а обновляются старые данные (при сброшенном флаге Запретить повторную загрузку чеков общепита).
