Обработка "Потери при обработке сырья"

Назначение

Обработка предназначена для редактирования записей регистра Обработка сырья, хранящего информацию о процентах потерь при обработке сырья. Данные представлены в виде дерева, причем записи могут группироваться по сырью, по блюду, по подразделению, по дате. На нижнем уровне иерархии расположены виды обработки сырья. Ветки, у которых цвет шрифта синий, не могут редактироваться: эти записи сделаны документами «Акт проработки сырья».

Порядок группировки записей можно менять, за исключением видов обработки (ввиду важности порядка следования видов обработки).

Для фильтрации необходимых записей применяются отборы.

Для добавления сырья и блюда используется подбор.

Относится к подсистеме: «Производство».

Формы

  • Форма обработки. Основная форма обработки.
  • Редактирование списка значений. Дополнительная форма, для редактирования списка значений.

Способ вызова

Вызывается из меню "Справочники --> Производство--> Механизм видов обработки --> Потери при обработке сырья".
