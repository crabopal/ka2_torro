Обработка «Доставка сообщений»

Назначение

Определяет основные функции по доставки сообщений обмена (транспорт).

 

Реквизиты

  • Настройка доставки. Указывает способ доставки сообщения. Ссылается на справочник Настройки доставки сообщений.
  • Узел обмена. Узел, с которым производится обмен. Ссылается на план обмена Кассовые узлы.
  • Прием. Признак выполнения приема сообщения обмена.
  • Отправка. Признак выполнения отправки сообщения обмена.

Способ вызова

Интерактивного вызова не предусмотрено.
