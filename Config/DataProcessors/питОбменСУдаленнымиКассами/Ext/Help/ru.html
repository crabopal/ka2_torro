Обработка «Обмен с удаленными кассами (фронтовые решения 1С-Рарус)»

Назначение

Обработка Обмен с удаленными кассами (фронтовые решения 1С-Рарус) предназначена для автоматического формирования и последующей публикации, и/или получения сообщений обмена. В качестве узлов обмена может быть указана ссылка на узел плана обмена Удаленные кассы. Список доступных действий:

  • Загрузка сообщения обмена (кнопка Загрузка)
  • Выгрузка сообщения обмена (кнопка Выгрузка)
  • Обмен сообщениями обмена (кнопка Обмен)

Так же через кнопку Еще доступны дополнительные действия:  

  • Полная регистрация всех данных для выгрузки в указанный узел (кнопка Полная регистрация всех данных)
  • Выгрузка начального образа информационной базы для указанного узла плана обмена (кнопка Выгрузка начального образа)

При открытии обработки происходит заполнение таблицы узлов обмена. Можно выбрать произвольные узлы для проведения обмена, выбрать все/снять выбор.

Закладка «Кассовые узлы»

  • Узел обмена. Узел плана обмена, с которым производится обмен данными. Ссылается на план обмена Кассовые узлы.
  • Настройка обмена. Настройка обмена данными. Задает способ обмена, каталог обмена и другие параметры. Ссылается на справочник Настройки доставки сообщений.
  • Версия фронт-офиса. Номер релиза фронт-офиса. Необходим для определения актуальности релиза фронт-офиса.
  • Префикс. Префикс узла плана обмена.
  • Последняя загрузка. Номер сообщения и время последней загрузки.
  • Последняя выгрузка. Номер сообщения и время последней выгрузки.

Закладка «Дополнительно»

  • Комментировать ход обмена. Задает необходимость комментирования обмена.
  • Комментировать ход обмена с детализацией до объектов. Задает необходимость комментирования каждого объекта обмена.
  • Вести журнал регистрации. Задает необходимость ведения журнала регистрации.
  • Количество элементов в транзакции. Устанавливает количество элементов данных в одной транзакции. Значение 0 соответствует выполнению обмена в рамках одной транзакции.
