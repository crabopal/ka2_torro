Параметры авторизации

Назначение

Форма предназначена для заполнения параметров авторизации обработки «Загрузка с сайта FoodCOST».

  • Имя пользователя. Логин подключения к базе данных сайта.
  • Пароль.  Пароль подключения к базе данных сайта.
  • Ключ интеграции. Ключ интеграции сервера.
  • Демонстрационный режим. При установке данного флага включается демонстрационный режим (без указания логина, пароля и ключа интеграции), при котором с сайта загружаются десять блюд для демонстрации обработки.

Способ вызова

Вызывается из формы обработки по гиперссылке Параметры подключения.
