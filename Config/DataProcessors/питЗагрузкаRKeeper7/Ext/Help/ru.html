Назначение 

 

Служит для загрузки данных о реализации из программы R-Keeper v.7.

 

Загрузка происходит поэтапно:

  • Подключение к базе R-Keeper v.7;
  • Установка соответствия данных;
  • Получение данных из R-Keeper v.7;
  • Создание документов Чеки Общепита.

 

Подключение к базе R-Keeper v.7


Для получения данных о реализации необходимо подключиться к базе R-Keeper v.7 через учетную запись. При первом запуске обработки система определяет заполнение реквизитов соединения с базой:

  • Если они не заполнены, то открывается форма создания новой учетной записи
  • Если заполнены, то производится попытка соединения:
    • В случае успеха пишется гиперссылка зеленого цвета «Подключение установлено» в верхнем левом углу;
    • В случае неуспеха пишется гиперссылка серого цвета «Подключение установлено» в верхнем левом углу;
    • Если параметры вовсе не заполнены, то красная надпись «Подключение не настроено».

 

В форме учетной записи необходимо указать:

  • Имя сервера MS SQL Server, на котором установлен и функционирует R-Keeper;
  • Базу данных R-Keeper на сервере MS SQL Server, с которой осуществляется обмен;
  • Логин и пароль администратора базы R-Keeper. При пустых значениях аутентификация будет происходить по текущему пользователю Windows.
  • В области Ведение учета в R-Keeper указывается дата, начиная с которой будут загружены данные из базы R-Keeper при первом фоновом обмене.

 

Установка соответствия данных


Установка соответствия данных осуществляется на закладке «Установка соответствий». Определен обязательный тип для заполнения соответствиями: Кассы ККМ и пять необязательных: ВСпособ оплат, Вид оплат, Номенклатура, Модификаторы, Причины отмен и списаний.

 

1. Для установки соответствия любого типа сначала необходимо получить объекты (кассу ККМ, способ/вид оплаты, номенклатуру, модификаторы, причины отмен и списаний) по кнопке Загрузить:

  • Алгоритмы получения касс ККМ/способов/видов оплат/причин отмен и списаний:
    • Все кассы ККМ/способов оплат/видов оплат/причины отмен и списаний - получение всех касс ККМ, способов и видов оплат, причин отмен и списаний базы R-Keeper;
    • По документам - получение номенклатуры по документам с хоз. операцией Продажа и Удаление.
  • Алгоритмы получения номенклатуры, модификаторов:
    • Вся номенклатура/Все модификаторы – получение всей номенклатуры или всех модификаторов из базы R-Keeper;
    • По продажам и списаниям – получение номенклатуры по документам с хоз. операцией Продажа и Удаление;
    • По списаниям - получение номенклатуры только по документам с хоз. операцией Удаление;
    • По продажам - получение номенклатуры только по документам с хоз. операцией Продажа. 

 

2. Далее необходимо заполнить соответствия автоматически через кнопку Заполнить соответствия:

  • Алгоритмы заполнения соответствий элементов R-Keeper и 1С:
    • По полному совпадению наименований – соответствие проставляется при полной идентичности наименования.
    • По частичному совпадению наименований - соответствие проставляется при частичном совпадении наименования, если в наименование 1С полностью входит наименование R-Keeper (например, номенклатуре R-Keeper с наименованием БОРЩ установится соответствующая номенклатура 1С с наименованием БОРЩ СО СМЕТАНОЙ). При этом можно установить реквизит Процент схожести наименования при частичном совпадении.
    • По совпадению шифра R-Keeper и кода 1C - соответствие проставляется при совпадении шифра R-Keeper и кода 1C.
    • По совпадению кода R-Keeper и кода 1C - соответствие проставляется при совпадении кодов R-Keeper и 1C.

 

Реквизит Процент схожести наименования при частичном совпадении служит для задания процента совпадения наименования элементов справочников решения 1С и базы R-Keeper.

 

Внимание! Установка низкого процента совпадения может привести к тому, что в соответствие будет подставлено некорректное значение. Рекомендуется указывать не менее 75% совпадения.

 

Если установлен флаг Создавать объекты при автоматическом заполнении соответствий, то при заполнении соответствиями с помощью пунктов меню кнопки «Заполнить соответствия» будут автоматически создаваться новые элементы справочников 1С (Кассы ККМ, Способы оплат, Виды оплат, Номенклатура, Модификаторы, Причины отмен и списаний).

 

В таблице соответствия имеется возможность проставления соответствий вручную, используя кнопки командной панели Вниз к незаполненному соответствию и Вверх к незаполненному соответствию можно переходить к данным, у которых нет соответствия.

 

Так же для удобства отображения и заполнения соответствий на закладке Кассы ККМ есть кнопка Только заполненные, при активации которой устанавливается отбор только по заполненным соответствиям. На остальных закладках кнопка Только незаполненные, при активации которой будут видно только строки с незаполненными соответствиями.  

 

Есть возможность установить отбор по кассам ККМ, у которых проставлены соответствия по контекстному меню Установить отбор:  

  • По подразделениям – устанавливается отбор по кассам ККМ определенных подразделений компании. Есть возможность указать как одно подразделение, так и несколько путем зажатия клавиши Ctrl и выделения нужного количества подразделений.
  • Очистить – убрать отборы по всем кассам.

 

Получение данных из R-Keeper v.7

 

По нажатию на кнопку Загрузить на закладке Продажи появляется контекстное меню, которое предлагает получить следующие виды данных из базы R-Keeper:

  • Продажи – загрузятся только документы продаж за указанный период;
  • Удаление – загрузятся только документы отмен за указанный период;
  • Продажи и удаления – загрузятся оба вида документов за указанный период.

 

Создание документов «Чеки Общепита»


Создание документов Чеки Общепит происходит по нажатию на кнопку Создать чеки Общепита . Если таблица продаж при этом не заполнена, то она заполняется по текущим установленным отборам.
Документы Чеки общепита могут создаваться со следующими хоз. операциями:

  • Продажа
  • Возврат
  • Отмена

 

Закладка «Параметры загрузки»

  • Создавать целевые документы из загруженных чеков Общепита – включает режим автоматического запуска обработки Загрузка из чеков Общепита после завершения процедур обмена с R-Keeper v.7.  
  • Параметры загрузки объектов - список типов объектов при загрузке. По каждому типу имеются параметры:
    • Обновлять - указывает на необходимость синхронизации имеющихся объектов 1С с объектами R-Keeper. 
    • Создавать - указывает на необходимость создавать объекты 1С при ненахождении соответствий с объектами R-Keeper.
    • Служебный каталог - служит для выбора группы справочника, в которую будут переносится созданные/обновленные объекты 1С. Если значение не выбрано, то объекты будут переносится в корневой уровень справочника.
    • При ошибке загрузки - выбор поведения программы при возникновении ошибок загрузки:
      • Продолжать загрузку – загрузка продолжается при возникновении ошибок
      • Не загружать данный чек – при возникновении ошибки не будет загружен чек, в котором она произошла
      • Прервать загрузку чеков – при возникновении первой ошибки загрузка будет прекращена

 

ВАЖНО! Если напротив типа объекта Модификатора стоит флаг Создавать, а у Номенклатуры нет, то для модификатора не создается новая номенклатура. Создается только в случае, когда флаг стоит в обоих местах.

 

После редактирования данные параметры обязательно необходимо сохранить по кнопке Записать.

 

  • Предварительная проверка заполненности соответствий - при установке данного флага происходит предварительная проверка заполненности соответсвий, если пользователь сразу пытается загрузить документы Чеки Общепита. При этом, если будут обнаружены незаполненные соответствия объектов (кроме касс ККМ), программа уточнит стоит ли продолжать загрузку. Если нажать - нет, то в соответствующих закладках (Способы/Виды оплат, Номенклатура, Модификаторы, Причины отмен и списаний) будут выведены только те объекты, у которых не заполнены соответствия.    
  • Параметры загрузки продаж:
    • Загружать позиции с нулевыми ценами – при установленном флаге в табличные части документов будет выгружаться и номенклатура с нулевыми ценами.
    • Выводить отчет по окончании загрузки – при установленном флаге выводится отчет с перечнем созданных документов

  • Параметры загрузки удалений – определяет как загружать документы с хоз. операцией Удаление в 1С (как Отмены или как Возвраты).

 

Режимы о6мена

  • Обмен возможно осуществить вручную, по нажатию кнопки Загрузить продажи. В данном случае обмен производится по периоду заданному в обработке.
  • Можно настроить расписание регламентного задания по кнопки в правом нижнем углу Показать расписание регламентного задания. По расписанию будет производится попытка обмена только по тем кассам ККМ, которые присутствуют в преднастроенном соответствии. В этом случае период загрузки определяется следующим образом:
    • Если обмен еще не производился по очередной кассе ККМ, то от реквизита Дата начала ведения учета (Сервис – Основная форма констант – Системные настройки – Интеграция R-Keeper v.7) до последней существующей продажи в R-Keeper.
    • Если обмен уже производился по данной кассе ККМ, то от даты последнего загруженного документа Чеки Общепита до последней существующей продажи в R-Keeper.
