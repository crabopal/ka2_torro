Назначение

Служит для отображения и редактирования состава и количества химико-энергетических характеристик номенклатуры с видом номенклатуры Товар или Блюдо. Для номенклатуры с видом номенклатуры Блюдо позволяет просматривать состав и количество химико-энергетических характеристик, рассчитанных по основной (актуальной) рецептуре блюда плюс химико-энергетические характеристики, введенные для этого блюда и конкретной рецептуры (либо всех рецептур этого блюда). Введенные данные сохраняются в регистре сведений Химико-энергетические характеристики.

Реквизиты

  • Количество и единица измерения номенклатуры - показывают, на какое количество в указанных единицах вводится содержание химико-энергетических характеристик.
  • Способ расчета калорийности - одно из значений:
    • По формуле
    • Суммированием
    • По константе
    • По рецептуре

Надпись <По константе> или <По рецептуре> зависит от реквизита Способ расчета калорийности в документе Рецептуры на закладке «Химико-энергетические характеристики». Если стоит По формуле,  то <По рецептуре>. В остальных случаях (и если табличная часть рецептуры пуста) - <По константе>

  • Формула расчета калорийности - формульная зависимость значения калорийности от содержания других ХЭХ.
  • Калорийность - рассчитанное значение калорийности в зависимости от способа и формулы ее расчета.

Если единица измерения номенклатуры для ХЭХ не задана, то у номенклатуры ищется единица измерения по умолчанию для ХЭХ (Общепит – Настройки – ХЭХ – Единица измерения по классификатору для ХЭХ), например, грамм. В случае, когда у номенклатуры такой единицы нет, подставляется основная единица измерения номенклатуры.
Единицу измерения для ХЭХ можно изменять. В этом случае будет предложено пересчитать количество уже введенных химико-энергетических характеристик.

 

При подсчете количества ХЭХ номенклатуры, входящей в состав какой-либо рецептуры блюда, происходит пересчет заданных значений количества химико-энергетических показателей. Например, для 100 г лимона задано 5 мг витамина С. Тогда в рецептуре блюда, в которой используется 2 кг лимона, содержание витамина С равно 5(мг) * 2(кг) * 1000(г/кг) / 100(г) = 100(мг), если базовой единицей номенклатуры является грамм, или 5(мг) * 2(кг) / (100(г) * 0,001(кг/г)) = 100(мг), если базовой единицей номенклатуры является килограмм.
Аналогично, если рассчитывается содержание ХЭХ блюда на какое-то количество, то также происходит пересчет количества ХЭХ. Пусть в приведенном выше примере 2 кг лимона содержится в 50 порциях блюда, а необходимо узнать, какое количество витамина С содержится в 3 кг блюда (пусть 1 пор = 0,2 кг). Так как в 2 кг лимона (50 порций блюда) содержится 100 мг витамина С, то в 3 кг блюда содержится 100(мг) * 3(кг) * 1/0,2(пор/кг) / 50(пор) = 30(мг), если базовой единицей для блюда является порция, или 100(мг) * 3(кг) / (50(пор) * 0,2(кг/пор)) = 30(мг).

 

Обработка содержит одну или две закладки:

  • Общие ХЭХ
  • ХЭХ рецептуры

 

На закладках Общие ХЭХ и ХЭХ рецептуры вводится химико-энергетическая характеристика и ее содержание в указанном количестве номенклатуры. Единица измерения ХЭХ заполняется автоматически тем значением, которое указано для химико-энергетической характеристики в справочнике Химико-энергетические характеристики.

 

Закладка «Общие ХЭХ»

 

Для номенклатуры вида Товар указывается содержание химико-энергетических характеристик номенклатуры. Эти значения справедливы для всех рецептур блюд, в которые входит данный товар.

 

Для номенклатуры вида Блюдо указывается содержание химико-энергетических характеристик номенклатуры независимо от рецептуры. Эти значения справедливы для всех рецептур данного блюда.

 

Есть возможность автоматического заполнения табличной части по меню Автозаполнение:

  • Автозаполнение предопределенными характеристиками (по справочнику Химико-энергетические характеристики)
  • Автозаполнение характеристиками для печати (по регистру сведений ХЭХ для печати)
  • Автозаполнение характеристиками из группы (по справочнику Группы ХЭХ)

 

Закладка «ХЭХ рецептуры»

 

В верхней табличной части указаны рецептуры блюда. В нижней табличной части указаны химико-энергетические характеристики и их количество по выбранной рецептуре.

 

Есть возможность автоматического заполнения табличной части по меню Автозаполнение:

  • Автозаполнение предопределенными характеристиками (по справочнику Химико-энергетические характеристики)
  • Автозаполнение характеристиками для печати (по регистру сведений ХЭХ для печати)
  • Автозаполнение характеристиками из группы (по справочнику Группы ХЭХ)

  • Автозаполнение общими характеристиками (по вкладке Общие ХЭХ)

 

Дополнительная информация

 

Расчет калорийности номенклатуры имеет свои особенности. С одной стороны, значение калорийности задается так же, как и значения других химико-энергетических характеристик. С другой стороны, калорийность может быть рассчитана как зависимость от содержания других ХЭХ в номенклатуре. При этом способ расчета калорийности (т.е. как обычная ХЭХ (Суммированием) или по формуле (По формуле)) может быть задан по умолчанию (Общепит – Настройки – ХЭХ – Единица измерения по классификатору для ХЭХ). Формула расчета калорийности также может быть задана по умолчанию (Общепит – Настройки – ХЭХ – Формула расчета калорийности). Например, формула расчета может иметь вид «4 * [Белки] + 9 * [Жиры] + 4 * [Углеводы]», т.е. рассчитываться в зависимости от содержания белков, жиров и углеводов в номенклатуре.


Кроме этого, способ и формула расчета калорийности могут задаваться в документе Рецептуры и для конкретной номенклатуры (при помощи данной обработки).

 

Для номенклатуры можно задавать следующие способы расчета калорийности:
  • По рецептуре - формула расчета калорийности берется из рецептуры.
  • По константе - берется формула расчета калорийности по умолчанию.
  • Суммированием - калорийность рассчитывается так же, как и все остальные ХЭХ.
  • По формуле - калорийность рассчитывается по указанной в обработке формуле.

 

Калорийность блюда в документе Рецептуры рассчитывается следующим образом. Если способ расчета установлен в Суммированием, то рассчитываются калорийность всех входящих в блюдо ингредиентов (в соответствии с заданными у них способами и формулами расчета калорийности), затем все значения суммируются. Если способ расчета установлен в По формуле, то калорийность рассчитывается по формуле, заданной в этом документе.

Содержание химико-энергетических характеристик в номенклатуре при печати Меню рассчитывается либо на единицу номенклатуры, указанную в рецептуре (для вида номенклатуры Блюдо), либо на указанное в данной обработке количество (для вида номенклатуры Товар).
При печати расширенного меню количество химико-энергетических характеристик рассчитывается либо на 100 единиц для ХЭХ по умолчанию (обычно, 100 г), либо, если у номенклатуры такой единицы нет, на 100 единиц в рецептуре (для номенклатуры вида Блюдо) или на 100 основных единиц (для номенклатуры вида Товар).

 

Способ вызова

 

Вызывается из справочника Номенклатура на панели формы.
