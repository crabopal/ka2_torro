Регистр сведений "Обработка сырья"

Назначение

Регистр сведений содержит данные на заданную дату о процентах потерь сырья при обработке в процессе приготовления блюд.

Относится к подсистеме: «Производство».

Параметры

Периодичность: Периодический с периодом "День"

Режим записи: Независимый

Измерения

  • Сырье. Ссылается на справочник «Номенклатура». Обрабатываемое сырье.
  • Вид обработки. Ссылается на справочник «Виды обработки сырья».  Вид обработки сырья.
  • Подразделение. Ссылается на справочник «Подразделения компании».  Подразделения, для которого устанавливаются потери (включая подчиненные подразделения).
  • Блюдо. Ссылается на справочник «Номенклатура».  Указывает, при приготовлении какого блюда происходит указанная потеря сырья. Если пустое, то запись относится ко всем блюдам.

Ресурсы

  • Процент потерь. Числовое значение. Процент потерь сырья при приготовлении блюд. 
  • Приоритет. Числовое значение. Порядок вида обработки сырья.

Реквизиты

  • Документ-регистратор. Документ, поместивший записи в регистр. Если пустое значение, то запись помещена вручную.

Формы

  • Форма списка. Основная форма списка и выбора. Используется для отображения и редактирования хранимой в регистре информации.

Способ вызова

Регистр редактируется с помощью специализированной обработки «Потери при обработки сырья», которая вызывается из меню "Справочники --> Производство--> Механизм видов обработки --> Потери при обработке сырья".
