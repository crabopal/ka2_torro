Регистр сведений «Роли пользователей фронта»

Назначение

Регистр предназначен для определения ролей пользователей во фронтовых решениях «1С:Ресторан» или «РестАрт». Настройка производится через специальную форму ролей, доступную через закладку «Сервис» в подсистеме «Общепит».

Работа с формой настройки ролей

Центральным элементом является дерево пользователей, при помощи которого можно добавлять/удалять/изменять состав ролей фронта для пользователей.

Дерево содержит два столбца: «Пользователь/Роль фронта» и «Пароль». Для добавления ролей пользователю, сначала необходимо добавить самого пользователя, сфокусировавшись на корень дерева и нажав кнопку Добавить. Далее необходимо сфокусироваться на пользователе и по нажатию на кнопку Добавить откроется форма выбора ролей фронта. Таким образом будет определен состав ролей фронта для выбранного пользователя. Колонка «Пароль» доступна для заполнения только для строк дерева, которые содержат пользователя. Данная колонка определяет пароль для входа в систему выбранного пользователя во фронтовых решениях. Установка ролей производится по нажатию кнопки Записать изменения. В случае успешного выполнения пользователю будет выдано соответствующее сообщение.

Способ вызова

Общепит - Сервис - Роли пользователей фронта
