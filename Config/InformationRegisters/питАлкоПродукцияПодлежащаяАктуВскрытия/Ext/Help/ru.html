Регистр сведений «Алко продукция подлежащая акту вскрытия»

Назначение

Регистр сведений предназначен для хранения списка соответствия между складом и номенклатурой, которая будет учитываться в журнале алкогольной продукции только по документам Акт вскрытия тары алкогольной продукции.

Измерения

  • Склад. Склад, по которому будет определяться номенклатура, подлежащая акту вскрытия. Ссылается на справочник Склады.  
  • Номенклатура. Номенклатура, подлежащая акту вскрытия. Остальная номенклатура по данному складу заполнится расчетным путем из движений документов. Если номенклатура не заполнена, считается, что вся алкогольная номенклатура по данному складу вводится только Актом вскрытия тары алкогольной продукции. Ссылается на справочник Номенклатура.
