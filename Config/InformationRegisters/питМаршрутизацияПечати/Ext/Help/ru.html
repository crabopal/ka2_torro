Регистр сведений «Маршрутизация печати»

Назначение

Предназначен для хранения способов печати позиций заказа в зависимости от различных условий. Используется только при наличии обмена по плану обмена Кассовые узлы с фронт-офисом, поддерживающим функции ресторана: РестАрт, 1С:Предприятие 8. Ресторан. В качестве условий для печати могут выступать: кассовый узел, номенклатура, используемый вид меню, зал печати, место печати.

Измерения

  • Кассовый узел. Кассовый узел, для которого задается место печати. При незаполненном значении кассового узла маршрутизация действует для всех кассовых узлов. Ссылается на план обмена Кассовые узлы.
  • Номенклатура. Номенклатура или группа Номенклатуры, для которой задается место печати. Ссылается на справочник Номенклатура.
  • Вид меню. Вид меню,  для которого задается место печати. Ссылается на справочник Виды меню.
  • Зал. Зал, для которого задается место печати. Ссылается на справочник Залы.
  • Место печати. Заданное место печати. Ссылается на справочник Места печати.
