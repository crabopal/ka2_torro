Регистр сведений «ХЭХ для печати»

Назначение

Регистр сведений ХЭХ для печати предназначен для хранения списка и порядка (приоритета) химико-энергетических характеристик, используемых для вывода в печатные формы, например, в технико-технологическую карту.

Измерения

  • Химико-энергетическая характеристика. Химико-энергетическая характеристика, которую необходимо выводить при печати. Ссылается на справочник Химико-энергетические характеристики.
  • Макет. Виды макетов химико-энергетических характеристик.

Ресурсы

  • Приоритет. Числовое значение. Определяет порядок вывода химикоэнергетических характеристик при печати. Чем меньше значение приоритета, тем раньше выводится характеристика.
  • Формировать группы при выводе. Тип значения: «Булево». Если флаг установлен, то при печати будут выводиться группы ХЭХ.
