Регистр сведений «Чеки общепита»

Назначение

Регистр сведений Чеки общепита предназначен для хранения связей между документами Чеки общепита, являющихся первичными документами и целевыми документами, которые были созданы в результате запуска обработки Загрузка из чеков общепита.

Как правило, одному первичному документу соответствует несколько целевых (учетных) документов.

Измерения

  • Документ регистратор. Первичный документ, на основании которого будет создан целевой документ. Ссылается на документ Чеки общепита.  
  • Документ приемник. Целевые документы, которые создаются в результате запуска обработки Загрузка из чеков общепита на основании данных первичных документов. Ссылается на документы Выпуск блюд, Отчет о розничных продажах. 
  • Обновлен приемник. При установке данного признака фиксируется факт обновления данных целевого документа. В противном случае указывает на повторную загрузку первичных документов из фронт-офиса и необходимость обновления целевого документа.

Реквизиты

  • Дата последнего обновления. Определяет дату и время последнего обновления документа с точностью до секунды.
