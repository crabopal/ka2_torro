Регистр сведений «Модификаторы номенклатуры»

Назначение

Регистр сведений Модификаторы номенклатуры предназначен для хранения списка модификаторов номенклатуры. Номенклатура и модификаторы могут указываться как для элементов, так и для групп справочников.

Измерения

  • Номенклатура. Номенклатура или группа Номенклатуры, для которой задается модификатор. Ссылается на справочник Номенклатура.
  • Модификатор. Модификатор или группа Модификаторов, для указанной номенклатуры. Ссылается на справочник Модификаторы.

  • Набор модификатора. Группа, в которую входит модификатор  для указанной номенклатуры. Ссылается на справочник Наборы модификаторов.

Способ вызова

Не предназначен для интерактивного вызова и редактирования.

 

Дополнительная информация

Установка значений для записи в данный регистр производится из обработки Модификаторы номенклатуры.
